# stack-directus-nextjs-dev (Gemini CLI Extension)

Directus + Next.js stack dev plugin. Integrates Directus headless CMS with Next.js App Router for content-driven applications.

## Install

```bash
gemini extensions install agents-store/gemini-ext-stack-directus-nextjs-dev
```

## Required environment variables

Set in `~/.gemini/settings.json` or shell environment:

- `DIRECTUS_ADMIN_TOKEN`
- `NEXT_PUBLIC_DIRECTUS_URL`
