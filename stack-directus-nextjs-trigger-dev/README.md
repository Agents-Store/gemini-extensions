# stack-directus-nextjs-trigger-dev (Gemini CLI Extension)

Directus + Next.js + Trigger.dev stack dev plugin. Adds self-hosted Trigger.dev as a workflow engine for AI agents, durable async logic, and scheduled jobs on top of the Directus + Next.js App Router stack.

## Install

```bash
gemini extensions install agents-store/gemini-ext-stack-directus-nextjs-trigger-dev
```

## Required environment variables

Set in `~/.gemini/settings.json` or shell environment:

- `DIRECTUS_ADMIN_TOKEN`
- `NEXT_PUBLIC_DIRECTUS_URL`
- `TRIGGER_API_URL`
- `TRIGGER_SECRET_KEY`
