# web-search-dev (Gemini CLI Extension)

Web search and scraping developer toolkit...

## Install

```bash
gemini extensions install agents-store/gemini-ext-web-search-dev
```

## Required environment variables

Set in `~/.gemini/settings.json` or shell environment:

- `CONTEXT7_API_KEY`
- `EXA_API_KEY`
- `FIRECRAWL_API_TOKEN`
- `JINA_API_KEY`
- `PERPLEXITY_API_KEY`
